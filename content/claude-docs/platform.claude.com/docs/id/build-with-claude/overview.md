## Fitur platform

Fitur-fitur Claude Platform yang berfungsi di seluruh API-nya. Halaman setiap fitur menjelaskan di mana Anda dapat menggunakannya.

<Tip>
  Anda dapat mengetahui kemampuan apa saja yang didukung suatu model secara terprogram. [Models API](https://platform.claude.com/docs/id/api/models/list) mengembalikan `max_input_tokens`, `max_tokens`, dan objek `capabilities` untuk setiap model yang tersedia.
</Tip>
