Permukaan API Claude diorganisasikan ke dalam lima area:

* **Kemampuan model:** Mengontrol cara Claude bernalar dan memformat respons.
* **Alat:** Memungkinkan Claude mengambil tindakan di web atau di lingkungan Anda.
* **Infrastruktur alat:** Menangani penemuan dan orkestrasi dalam skala besar.
* **Manajemen konteks:** Menjaga sesi yang berjalan lama tetap efisien.
* **File dan aset:** Mengelola dokumen dan data yang Anda berikan kepada Claude.

Jika Anda baru memulai, mulailah dengan [kemampuan model](https://platform.claude.com/docs/id/build-with-claude/overview#model-capabilities) dan [alat](https://platform.claude.com/docs/id/build-with-claude/overview#tools). Kembali ke bagian lainnya ketika Anda siap mengoptimalkan biaya, latensi, atau skala.

Untuk administrasi dan tata kelola, lihat [Admin API](https://platform.claude.com/docs/id/manage-claude/admin-api), [Usage and Cost API](https://platform.claude.com/docs/id/manage-claude/usage-cost-api), dan [Compliance API](https://platform.claude.com/docs/id/manage-claude/compliance-api).

## Ketersediaan fitur

Kolom Ketersediaan di setiap tabel berikut mencantumkan platform yang menawarkan suatu fitur. Platform yang tercantum tanpa label menawarkan fitur tersebut sebagai stabil, didukung penuh, dan direkomendasikan untuk penggunaan produksi, tanpa header beta dan dengan jaminan [pembuatan versi](https://platform.claude.com/docs/id/api/versioning) API standar. Label setelah nama platform menandai salah satu klasifikasi berikut pada platform tersebut. Tidak semua fitur melewati setiap tahap, dan suatu fitur dapat masuk pada tahap mana pun atau melewati tahap tertentu.

| Klasifikasi    | Deskripsi                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Beta**       | Fitur pratinjau yang digunakan untuk mengumpulkan umpan balik dan melakukan iterasi pada kasus penggunaan yang belum matang. Ketersediaan mungkin terbatas, termasuk melalui persyaratan pendaftaran atau daftar tunggu, dan mungkin tidak diumumkan secara publik. Fitur dapat berubah secara signifikan atau dihentikan berdasarkan umpan balik. Tidak dijamin untuk penggunaan produksi berkelanjutan. Perubahan yang merusak kompatibilitas mungkin terjadi dengan pemberitahuan, dan beberapa batasan khusus platform mungkin berlaku. Fitur beta pada Claude API dan [Claude Platform on AWS](https://platform.claude.com/docs/id/build-with-claude/claude-platform-on-aws) memiliki [header beta](https://platform.claude.com/docs/id/api/beta-headers). |
| **Deprecated** | Fitur masih berfungsi tetapi tidak lagi direkomendasikan. Jalur migrasi dan jadwal penghapusan disediakan.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Retired**    | Fitur tidak lagi tersedia.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

**Label platform:** Claude API (pihak pertama Anthropic) · [Bedrock](https://platform.claude.com/docs/id/build-with-claude/claude-in-amazon-bedrock) (dioperasikan AWS) · [Claude Platform on AWS](https://platform.claude.com/docs/id/build-with-claude/claude-platform-on-aws) (dioperasikan Anthropic di AWS) · [Google Cloud](https://platform.claude.com/docs/id/build-with-claude/claude-on-vertex-ai) (dioperasikan Google) · [Microsoft Foundry](https://platform.claude.com/docs/id/build-with-claude/claude-in-microsoft-foundry) (dioperasikan Anthropic di Azure)

## Kemampuan model

Cara untuk mengarahkan Claude dan output langsung Claude, termasuk format respons, kedalaman penalaran, dan modalitas input.

<Tip>
  Anda dapat menemukan kemampuan apa saja yang didukung suatu model secara terprogram. [Models API](https://platform.claude.com/docs/id/api/models/list) mengembalikan `max_input_tokens`, `max_tokens`, dan objek `capabilities` untuk setiap model yang tersedia.
</Tip>

Kolom ZDR menunjukkan apakah suatu fitur tersedia di bawah pengaturan "Zero Data Retention" (Retensi Data Nol), atau ZDR. Untuk sebagian besar fitur, hal ini hanya bergantung pada apa yang disimpan oleh mekanisme fitur tersebut; untuk fitur yang terikat pada model tertentu, ketersediaan ZDR tingkat model juga berlaku. Lihat [Persyaratan retensi data khusus model](https://platform.claude.com/docs/id/manage-claude/api-and-data-retention#model-specific-data-retention-requirements).
