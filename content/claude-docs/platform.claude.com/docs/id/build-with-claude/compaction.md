“Compaction” (pemadatan) menggantikan giliran-giliran lama dalam percakapan dengan ringkasan yang ditulis Claude di server, sehingga Anda tidak memerlukan kode peringkasan sendiri. Compaction menjaga percakapan panjang atau tugas agen tetap berada di dalam “context window” (jendela konteks), dan menjaga konteks aktif tetap kecil, karena kualitas respons menurun seiring bertambah panjangnya percakapan.

Jika Anda ingin melewati ikhtisar ini, mulailah dengan [Compaction sesuai permintaan](https://platform.claude.com/docs/id/build-with-claude/compaction-on-demand) untuk menambahkan compaction ke aplikasi Anda. Meskipun fitur tersebut dan [Compaction pada ambang batas token](https://platform.claude.com/docs/id/build-with-claude/compaction-threshold) sama-sama masih dalam beta, Compaction sesuai permintaan mencakup lebih banyak kasus penggunaan umum. Untuk menghapus hasil alat lama atau blok pemikiran lama berdasarkan aturan alih-alih meringkasnya, lihat [Pengeditan konteks](https://platform.claude.com/docs/id/build-with-claude/context-editing).

## Opsi compaction sesuai permintaan

[Compaction sesuai permintaan](https://platform.claude.com/docs/id/build-with-claude/compaction-on-demand) menunjukkan loop yang meringkas seluruh percakapan sementara aplikasi Anda menunggu. Dua halaman pertama dalam daftar ini mengubah cara loop tersebut berjalan, dan Anda dapat menggabungkan keduanya. Halaman ketiga berlaku jika Anda mengirim kembali blok pemikiran dan melakukan salah satu dari keduanya.

* [Compaction yang mempertahankan giliran terbaru](https://platform.claude.com/docs/id/build-with-claude/compaction-keep-recent-turns): ketika beberapa giliran terakhir harus sampai ke Claude kata demi kata. Ringkasan hanya mencakup giliran-giliran yang lebih lama.
* [Compaction di latar belakang](https://platform.claude.com/docs/id/build-with-claude/compaction-background): ketika percakapan tidak dapat berhenti sejenak untuk menunggu ringkasan. Permintaan berjalan sementara pekerjaan berlanjut, dan Anda menukarkan blok tersebut ke dalam percakapan saat blok itu tiba.
* [Compaction dan pemikiran yang dipertahankan](https://platform.claude.com/docs/id/build-with-claude/compaction-thinking-blocks): jika Anda mengirim kembali blok pemikiran pada model dengan pemikiran yang dipertahankan dan Anda mempertahankan giliran terbaru atau melakukan compaction di latar belakang. Jika tidak, lewati halaman ini.
* [Menulis prompt peringkasan Anda sendiri](https://platform.claude.com/docs/id/build-with-claude/compaction-on-demand#write-your-own-summarization-prompt): ketika ringkasan default menghilangkan sesuatu yang dibutuhkan oleh giliran berikutnya. Prompt Anda menggantikan prompt default.
* [Melakukan compaction lagi](https://platform.claude.com/docs/id/build-with-claude/compaction-on-demand#compact-again): ketika percakapan yang sudah diawali dengan blok compaction kembali menjadi panjang.

Temukan topik-topik berikut di halaman lain:

* [Meminta ringkasan](https://platform.claude.com/docs/id/build-with-claude/compaction-on-demand#request-a-summary) ada di Compaction sesuai permintaan.
* [Melanjutkan dari ringkasan](https://platform.claude.com/docs/id/build-with-claude/compaction-on-demand#continue-from-the-summary) ada di Compaction sesuai permintaan. Ketentuan yang menjaga pemikiran tetap valid dalam giliran yang Anda pertahankan ada di [Compaction dan pemikiran yang dipertahankan](https://platform.claude.com/docs/id/build-with-claude/compaction-thinking-blocks).
* Ketika tidak ada ringkasan yang dikembalikan: lihat [Menangani ringkasan yang hilang atau error](https://platform.claude.com/docs/id/build-with-claude/compaction-on-demand#when-no-summary-comes-back) di Compaction sesuai permintaan.
* Bagaimana fitur ini berpadu dengan bagian API lainnya: lihat [Batasan dan interaksi dengan fitur lain](https://platform.claude.com/docs/id/build-with-claude/compaction-on-demand#how-it-fits-with-the-rest-of-the-api) di Compaction sesuai permintaan.
* Memahami penggunaan: lihat [Menghitung penggunaan compaction](https://platform.claude.com/docs/id/build-with-claude/compaction-on-demand#understanding-usage) untuk compaction sesuai permintaan, atau [Memahami penggunaan](https://platform.claude.com/docs/id/build-with-claude/compaction-threshold#understanding-usage) untuk compaction ambang.
* Kompatibilitas: setiap jenis memiliki header beta sendiri, sehingga setiap halaman memiliki bagiannya sendiri: [Dukungan API untuk compaction sesuai permintaan](https://platform.claude.com/docs/id/build-with-claude/compaction-on-demand#availability-feature-support) dan [Dukungan API untuk compaction ambang](https://platform.claude.com/docs/id/build-with-claude/compaction-threshold#availability-feature-support).

Compaction ambang batas memiliki halamannya sendiri: [Compaction pada ambang batas token](https://platform.claude.com/docs/id/build-with-claude/compaction-threshold).
