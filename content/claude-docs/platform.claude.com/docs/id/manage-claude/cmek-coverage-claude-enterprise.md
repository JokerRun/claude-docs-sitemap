Untuk Claude Platform, lihat [Cakupan CMEK di Claude Platform](https://platform.claude.com/docs/id/manage-claude/cmek-coverage-claude-platform).

## Dienkripsi dengan kunci Anda

* Konten chat, termasuk skill dan plugin.
* Lampiran chat dan lampiran proyek.
* Artifacts, termasuk Claude Design, Claude Slides, dan Claude Docs dalam percakapan dan tab **Artefak**.
* Claude Code di CLI, termasuk konten pesan.
* Cowork di Claude Desktop.
* Office agents, termasuk Claude for Outlook (beta).
* Claude in Chrome.
* Claude Science, yang masih dalam versi beta.
* Versi plugin [Plugins API](https://platform.claude.com/docs/id/manage-claude/plugins-api#customer-managed-encryption-keys) (beta): deskripsi, catatan rilis, komponen, dan file setiap versi. Halaman tersebut mencantumkan permintaan mana yang tetap berfungsi selama kunci Anda tidak dapat digunakan.
* [Transkrip sesi lokal](https://platform.claude.com/docs/id/manage-claude/compliance-sessions#retrieve-local-sessions) Compliance API dari sesi di mesin pengguna. Jika kunci Anda tidak dapat digunakan, endpoint messages mengembalikan [503 Service Unavailable](https://platform.claude.com/docs/id/manage-claude/compliance-errors#local-sessions-temporarily-unavailable) alih-alih konten transkrip. Metadata sesi tetap dicantumkan.
* Backup dan snapshot, yang mewarisi kunci tersebut.

## Dinonaktifkan atau berubah

Fitur beta dan pratinjau riset mungkin tidak dilindungi oleh “customer-managed encryption keys” (kunci enkripsi yang dikelola pelanggan), atau CMEK, dan dapat mengalami gangguan di organisasi CMEK.

Daftar ini tidak lengkap. Tinjau daftar ini bersama tim Anda sebelum Anda menyiapkan CMEK.

| Fitur                                                                                                                                       | Yang dilihat pengguna                                                                                                                                                                                                                                                                         |
| ------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Claude Code di web                                                                                                                          | Nonaktif. Sesi baru tidak dapat dimulai, meskipun admin mengaktifkan produk tersebut.                                                                                                                                                                                                         |
| Claude Code Desktop                                                                                                                         | Nonaktif hingga admin mengaktifkannya. Tersedia untuk sesi lokal setelah diaktifkan di [claude.ai > Pengaturan organisasi > Claude Code](https://claude.ai/admin-settings/claude-code).                                                                                                       |
| [Code Review](https://code.claude.com/docs/id/code-review)                                                                                  | Nonaktif. Code Review tidak berjalan pada pull request.                                                                                                                                                                                                                                       |
| Artifacts                                                                                                                                   | Berubah. Untuk organisasi yang menggunakan ZDR Claude Code: Artifacts, termasuk Claude Design, Claude Slides, dan Claude Docs dalam percakapan dan tab **Artefak**, tidak dapat diaktifkan.                                                                                                   |
| Publikasi dan berbagi artifact                                                                                                              | Berubah. Artifact dapat dibagikan di dalam organisasi Anda, tetapi tidak secara publik.                                                                                                                                                                                                       |
| Analitik: skill dan konektor                                                                                                                | Berubah. Analitik admin untuk skill dan konektor, di dasbor analitik claude.ai dan melalui [Claude Enterprise Analytics API](https://platform.claude.com/docs/id/manage-claude/analytics-api), tidak mencakup penggunaan di chat, dan menyembunyikan nama skill, plugin, dan konektor kustom. |
| Penilaian respons: jempol ke atas dan jempol ke bawah                                                                                       | Nonaktif. Anggota tidak dapat menilai respons Claude.                                                                                                                                                                                                                                         |
| [Pemindaian keamanan skill dan plugin](https://platform.claude.com/docs/id/agents-and-tools/agent-skills/enterprise#skill-content-scanning) | Nonaktif. Pengaturan ini tidak dapat diaktifkan, dan skill serta plugin diinstal tanpa pemindaian.                                                                                                                                                                                            |
| Claude in Slack (beta)                                                                                                                      | Nonaktif. Claude menolak permintaan, meskipun admin mengaktifkan produk tersebut.                                                                                                                                                                                                             |
| Analitik: laporan pintar dan metrik kontribusi                                                                                              | Nonaktif. Analitik tertentu dinonaktifkan, terlepas dari pengaturan admin: laporan pintar Claude (di claude.ai/analytics/insights) dan metrik kontribusi Claude Code dari GitHub (beta, di claude.ai/analytics/claude-code).                                                                  |
| Claude Security (beta)                                                                                                                      | Nonaktif. Fitur beta, dinonaktifkan terlepas dari pengaturan admin.                                                                                                                                                                                                                           |
| Tugas terjadwal cloud (pratinjau riset)                                                                                                     | Nonaktif. Fitur pratinjau riset, dinonaktifkan terlepas dari pengaturan admin.                                                                                                                                                                                                                |
| Aplikasi Claude Design mandiri (sedang dihentikan)                                                                                          | Tidak didukung. Lihat [Dienkripsi dengan kunci Anthropic](https://platform.claude.com/docs/id/manage-claude/cmek-coverage-claude-enterprise#encrypted-with-anthropics-key).                                                                                                                   |

## Dienkripsi dengan kunci Anthropic

Fitur yang menyimpan data ini tetap tersedia, tetapi data tersebut tidak dienkripsi dengan kunci Anda. Anda dapat menonaktifkan beberapa fitur ini di **Pengaturan**.

| Data                                               | Detail                                                                                                                                                                                                                                                                                                                                                                                                                         |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Data yang sudah ada sebelum penyiapan kunci        | Ditulis sebelum [kunci Anda mulai berlaku](https://platform.claude.com/docs/id/manage-claude/cmek-how-it-works#when-your-key-takes-effect).                                                                                                                                                                                                                                                                                    |
| Aplikasi Claude Design mandiri (sedang dihentikan) | Aplikasi Claude Design mandiri di claude.ai/design tidak didukung dengan CMEK, dan datanya mungkin tidak dienkripsi dengan kunci Anda. Aplikasi mandiri ini akan ditutup. Claude Design dalam percakapan dan tab **Artefak** dienkripsi dengan kunci Anda, sebagaimana tercantum di [Dienkripsi dengan kunci Anda](https://platform.claude.com/docs/id/manage-claude/cmek-coverage-claude-enterprise#encrypted-with-your-key). |
| Preferensi pribadi dan Instruksi global Cowork     | [Preferensi pribadi - bagian Instruksi untuk Claude](https://claude.ai/new#settings/account) dan Instruksi global Cowork. Keduanya diatur di tingkat akun dan dibagikan ke semua organisasi milik seorang pengguna.                                                                                                                                                                                                            |
| Data akun untuk pengguna di organisasi Anda        | Mencakup nama, alamat email, dan foto profil.                                                                                                                                                                                                                                                                                                                                                                                  |
| Catatan yang dipreservasi                          | Anthropic dapat mempreservasi catatan tertentu [dalam tiga kasus sempit](https://platform.claude.com/docs/id/manage-claude/cmek-data-retention#limited-preservation-outside-your-key).                                                                                                                                                                                                                                         |
| Telemetri Claude Code                              | Saat Claude Code terhubung melalui gateway atau proxy LLM (`ANTHROPIC_BASE_URL` kustom), CMEK tidak berlaku untuk telemetri operasional Claude Code. Untuk menonaktifkan telemetri ini, atur variabel lingkungan `DISABLE_TELEMETRY` ke `1`, sebagaimana dijelaskan di bagian [Layanan telemetri](https://code.claude.com/docs/id/data-usage#telemetry-services) dalam dokumentasi Claude Code.                                |
