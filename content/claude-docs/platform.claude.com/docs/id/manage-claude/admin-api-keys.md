Kunci Admin API mengautentikasi panggilan ke API yang mengelola dan melaporkan organisasi Anda, seperti [Admin API](https://platform.claude.com/docs/id/manage-claude/admin-api) dan [Compliance API](https://platform.claude.com/docs/id/manage-claude/compliance-api). Satu kunci dapat berfungsi dengan beberapa API ini.

## Kunci mana yang Anda butuhkan?

Kunci yang Anda butuhkan bergantung pada produk Claude mana yang digunakan organisasi Anda: Claude Console (Claude Platform) atau Claude Enterprise.

Sebagian besar kunci hanya menjangkau organisasi tempat Anda membuatnya. Beberapa kunci, seperti kunci dengan scope Compliance API, grup, atau audit, dapat menjangkau lebih jauh jika perusahaan Anda menautkan organisasinya di bawah [organisasi induk](https://platform.claude.com/docs/id/manage-claude/compliance-api-access#which-key-do-you-need). Jika perusahaan Anda menggunakan Claude Console dan Claude Enterprise, buat satu kunci di masing-masing.

## Membuat kunci untuk organisasi Claude Console

Akun Claude Console individual tidak dapat membuat kunci ini, jadi [siapkan organisasi](https://platform.claude.com/docs/id/manage-claude/admin-api#availability) terlebih dahulu. Untuk menggunakan kunci dengan Activity Feed, [aktifkan Compliance API](https://platform.claude.com/docs/id/manage-claude/compliance-api-access#set-up-the-compliance-api) sebelum Anda membuatnya.

<Steps>
  <Step title="Buka pengaturan Kunci admin">
    Masuk ke Claude Console sebagai [admin organisasi](https://platform.claude.com/docs/id/manage-claude/admin-api#organization-roles-and-permissions). Buka halaman [Kunci admin](https://platform.claude.com/settings/admin-keys) (`platform.claude.com/settings/admin-keys`).
  </Step>

  <Step title="Buat kunci">
    Klik **Buat kunci admin**, beri nama, pilih [masa kedaluwarsa kunci](https://platform.claude.com/docs/id/manage-claude/authentication#key-expiration), lalu klik **Tambahkan**.
  </Step>

  <Step title="Salin dan simpan secret">
    Salin secret yang ditampilkan (diawali dengan `sk-ant-admin01-`) dan simpan di pengelola secret Anda. Secret lengkap hanya ditampilkan satu kali.
  </Step>
</Steps>

## Membuat kunci untuk organisasi Claude Enterprise

<Steps>
  <Step title="Buka pengaturan API">
    Masuk ke claude.ai sebagai [pemilik utama atau pemilik organisasi](https://platform.claude.com/docs/id/manage-claude/user-management#organization-roles). Buka [claude.ai > Pengaturan organisasi > API](https://claude.ai/admin-settings/api-access) dan temukan bagian **Kunci**.
  </Step>

  <Step title="Buat kunci">
    Klik **Buat kunci**, beri nama kunci, dan pilih scope yang Anda butuhkan dari [tabel scope](https://platform.claude.com/docs/id/manage-claude/admin-api-keys#choose-scopes-for-a-claude-enterprise-key). Pemilik utama dapat menggabungkan scope dari API yang berbeda (misalnya, `read:analytics` dan `read:spend_limits`) pada satu kunci.

    Jika opsi **Akses kunci** muncul saat Anda memilih scope Compliance API, **Hanya organisasi ini** dipilih secara default. Untuk menjangkau setiap organisasi di bawah organisasi induk Anda, pilih **Semua organisasi**. Kunci seperti itu hanya dapat memiliki scope Compliance API, grup, dan audit.

    Klik **Buat**. Jika kunci memiliki scope `delete:compliance_user_data`, klik juga **Konfirmasi dan buat kunci**.
  </Step>

  <Step title="Salin dan simpan secret">
    Salin secret yang ditampilkan (diawali dengan `sk-ant-api01-`) dan simpan di pengelola secret Anda. Secret lengkap hanya ditampilkan satu kali.
  </Step>
</Steps>

## Memilih scope untuk kunci Claude Enterprise

Saat Anda membuat kunci Claude Enterprise, pilih setiap scope yang diperlukan oleh API yang akan Anda panggil. Scope ditetapkan saat pembuatan; untuk menambahkan scope di kemudian hari, buat kunci baru. Kunci yang hanya memiliki scope Compliance API juga disebut Compliance Access Key. Kunci yang hanya memiliki `read:analytics` juga disebut kunci Analytics API.

Untuk membaca plugin organisasi lain, lihat [Membaca organisasi lain di bawah induk yang sama](https://platform.claude.com/docs/id/manage-claude/plugins-api#reading-another-organization-under-the-same-parent).

## Menggunakan kunci

Sertakan kunci dalam header `x-api-key` pada setiap permintaan. Lihat dokumentasi masing-masing API untuk contoh permintaan lengkap.

Panggilan ke endpoint di luar scope kunci akan mengembalikan `403 Forbidden`. Pesan kesalahan menyebutkan scope yang diterima endpoint.

Baik kunci Claude Console maupun kunci Claude Enterprise tidak berfungsi dengan endpoint akun layanan, penerbit federasi, atau aturan federasi milik Admin API. Endpoint tersebut hanya menerima token bearer OAuth dengan scope `org:admin`. Lihat [Token bearer OAuth](https://platform.claude.com/docs/id/manage-claude/admin-api#oauth-bearer-token).
