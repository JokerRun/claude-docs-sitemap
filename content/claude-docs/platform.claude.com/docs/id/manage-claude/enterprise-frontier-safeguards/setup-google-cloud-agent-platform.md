Dengan [Enterprise Frontier Safeguards](https://platform.claude.com/docs/id/manage-claude/enterprise-frontier-safeguards/overview) (EFS), bucket Cloud Storage di proyek Google Cloud Anda menyimpan salinan terenkripsi dari prompt dan respons yang dicakup oleh EFS. EFS masih dalam tahap beta.

Access Transparency tidak mencakup permintaan Agent Platform Anda.

Untuk menyiapkan EFS, hubungi tim akun Anthropic Anda untuk mendapatkan akses dan panduan penyiapan. Beri tahu mereka terlebih dahulu jika “data retention” (retensi data) atau “data sharing” (berbagi data) aktif untuk model Claude mana pun di proyek Anda. EFS hanya mencakup endpoint dan model yang tercantum dalam panduan penyiapan, dan tidak mencakup “batch prediction” (prediksi batch).

Tanyakan juga kepada tim akun Anda tentang penyimpanan, kunci, transkrip, dan Safety Cases, karena halaman EFS lainnya menjelaskan Claude Console.
