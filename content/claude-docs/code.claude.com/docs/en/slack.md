# Claude Code in Slack

> What to use in place of the earlier Claude Code in Slack, on Team, Enterprise, Pro, Max, and Ultra plans.

The earlier Claude Code in Slack is retired. In a workspace that isn't connected to Claude Tag, `@Claude` replies that the workspace isn't set up for Claude Tag.

* **Team and Enterprise plans:** use [Claude Tag](https://claude.com/docs/claude-tag/overview) if it's in your channel. If it isn't, see [how to set it up](https://claude.com/docs/claude-tag/admins/setup-overview). To move a workspace from the earlier version, see [the migration guide](https://claude.com/docs/claude-tag/admins/migrate-from-earlier).
* **Pro, Max, and Ultra plans:** Claude Tag isn't available on individual plans. Start tasks in [Projects](https://code.claude.com/docs/en/claude-projects.md) if your account has them, or in [cloud sessions](https://code.claude.com/docs/en/claude-code-on-the-web.md).
